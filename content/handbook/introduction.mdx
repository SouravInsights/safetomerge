# Introduction

Welcome to the handbook. This is where you will document how to safely merge AI-generated code.

## Why this exists

Software is moving faster than humans can review it. We need a new way to observe, understand, change, verify, ship, and learn from code changes.

> "The review pipeline that worked when humans wrote every line is starting to break down."

This handbook is your guide to rebuilding that pipesbbsbsline for the agentic era.
